# HOJA QUIZ Phase 2D 인수인계 — 감독 검토 요청

## 기준과 변경

기준은 Phase 2C 조건부 PASS `7b599b7df39197c52dedf13f5a9e5417802dfe58`, 개발 정본은 `web/current/`다. 배포판은 `node tools/build_current.mjs`로 `dist-current/`에, 시험판은 `HOJA_TEST_PROBE=1 node tools/build_current.mjs`로 `dist-current-test/`에 만든다. 이번 최종 배포 게임 버전은 `3808d83568`이다.

- `112a929`: 교사·학생 HTML에 각각 중복된 Ogg 3곡을 내용 해시가 들어간 `assets/audio/` 공용 파일로 이동했다. `preload="none"`, 곡 선택·재생 순서와 오디오 객체는 유지한다. 파일 바이트와 기준판의 내장 바이트를 대조하고 Chrome에서 세 곡을 재생했다.
- `91a2ba9`: 두 페이지의 동일한 인트로 코드를 `js/intro-shared.js`로 분리했다. 원래 script 위치에서 동기 로드하며 원래 코드 바이트와 초기화 순서를 시험한다. 누락·순서 검사는 계속 수행한다.
- `49ce291`: 빌드 시 로컬 JS URL에 각 파일 내용 해시를 붙이고 아케이드 URL에 게임 버전을 전달한다. 아케이드는 요청 버전과 접근 가능한 부모 페이지 버전을 자신의 빌드 버전과 비교하여 다르면 실행을 중단하고 새로고침을 안내한다. 구버전 부모가 버전 매개변수 없이 iframe을 여는 경우도 시험했다. 기존 QR 형식과 카트리지 버전 정책은 유지한다.
- `2ef5f0f`: 학생 페이지의 숨겨진 교사용 카탈로그·저장소 선택·모드 선택 코드와 거기서만 쓰는 과목 아이콘을 제거했다. 교사용 코드는 `index.html`에 보존하고 공용 서비스·게임 진입은 계속 사용한다. 기존 공유 DOM과 스타일 중 게임 진입이 참조하는 부분은 유지했다.
- `0c91a9e`: 실제 네트워크 시험에 학생이 교사 전용 QR 스크립트를, 교사가 학생 전용 스크립트를 요청하지 않는다는 검사를 추가했다.

## 전후 파일 크기

단위는 바이트다. 파일 크기는 압축 전 원본이며, 이미지·음원은 data URL에서 디코딩한 크기를 별도로 표기한다. `js` 합계에는 vendor JS도 포함한다. 독립 CSS 파일과 독립 이미지 파일은 두 빌드 모두 없다.

## 실제 요청과 전송 측정

`verification/phase2d/measure.mjs`는 Chrome DevTools Protocol `encodedDataLength`를 합산한다. 교사·학생은 독립 브라우저 컨텍스트, 재접속은 같은 컨텍스트에서 새 페이지를 사용한다. 각 경로는 게임 장면 준비 후 500ms까지 관찰하고 난수 시드 314159로 곡 선택을 맞춘다. 숫자는 HTTP 헤더가 포함될 수 있는 실제 전송량이며 요청 수에는 캐시에서 처리된 요청도 포함된다. 게임 선택·클릭 시간은 장면 준비 시간에 포함하지 않는다.

표는 로컬 시험 서버가 HTML에 `no-cache`, 나머지에 `max-age=3600`을 주고 텍스트를 gzip으로 압축한 경우다. Phaser CDN은 자체 응답 헤더를 사용한다. 운영 서버의 실제 압축과 캐시 설정을 검증한 수치는 아니다. 각 값은 단일 실행이므로 시간 차이는 안정적인 성능 향상의 증거가 아니다.

| --- | --- | --- | --- | --- | --- |
| 교사 | 첫 접속 | 40 → 42 | 1 → 1 | 3,459,512 → 2,315,236 | 2,954 → 2,937 |
| 교사 | 재접속 | 39 → 41 | 34 → 36 | 3,097,156 → 1,402,580 | 2,540 → 2,560 |
| 학생 | 첫 접속 | 38 → 40 | 1 → 1 | 3,447,293 → 2,232,828 | 1,541 → 1,497 |
| 학생 | 재접속 | 38 → 40 | 33 → 35 | 3,097,142 → 1,332,369 | 1,457 → 1,295 |

비압축 전송 바이트는 교사 첫 접속 5,545,741→3,816,166, 재접속 5,050,773→2,428,410; 학생 첫 접속 5,489,229→3,652,319, 재접속 5,050,726→2,321,024다. 기준·최종 세부 요청, 각 화면의 페이지 로드 시간, 압축·비압축 개별 결과는 `verification/phase2d/baseline-serial-gzip.json`, `baseline-serial-plain.json`, `final-gzip.json`, `final-plain.json`에 보존한다. 첫 접속 요청은 공용 인트로와 선택된 음악으로 2건 늘었다.

## 배포 캐시 조건

실제 운영 환경에는 변경하지 않았다. 향후 서버는 HTML과 `BUILD.json`·카트리지 목록에 재검증을 적용하고, 내용 해시가 붙은 정적 리소스에는 긴 캐시를 적용할 수 있다. JS 쿼리 문자열 전체를 캐시 키에 포함해야 하며 새 빌드는 원자적으로 반영해야 한다. 다른 호스팅의 헤더, CDN의 쿼리 취급, 부분 배포 및 오프라인 서비스워커는 별도 검증이 필요하다. 빌드가 새 버전으로 바뀌면 기존 게임 버전 QR은 기존 정책대로 거부된다.
