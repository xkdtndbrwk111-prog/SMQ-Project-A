## 실제 엔진의 게임 시간

- 기본 제한시간 900초. 남은 200초에 석양 전환이 시작되고 100초에 밤 전환·가로등 점등·물음표 방향 안내가 시작된다. 0초에는 기존 TIME UP 및 결산 경로를 사용한다. 문제 풀이·수동 일시정지·쓰러짐 중 시간 정지 처리는 기존 구조를 보존한다.
- `hojaCreateTimeSettings(durationSeconds)`는 기본 900초, 정수·60초 단위, 가안 300~1800초를 검증한다. `startStage`가 새 게임 시작 시 설정을 생성·고정하고 같은 객체의 석양·밤·안내 임계값을 사용한다. 현재 싱글에서 선택·변경하는 UI나 공개 학생 조작 API는 없다. 향후 신뢰할 수 있는 방 설정 전달·서버 검증은 아직 구현되지 않았다.
- 비기본 시간의 `round(시간×2/9)`, `round(시간/9)`는 가안이며 한 함수에 모았다. 예: 600초는 133/67초. 900초의 200/100초는 확정 규격이다. 실제 새 900초 기준값은 `verification/phase3b1/time-baseline.json`에 별도로 기록한다.
- 시험 빌드만 `HOJA_TEST_LEGACY_TIME`을 통해 이전 600초·100/50초 상태를 재현한다. 기존 Phase 2 기준 trace와 FINISH 63점은 이 경로로 다시 비교하며 기준 파일을 덮어쓰지 않았다. 배포 빌드에 이 시험 제어는 들어가지 않는다.

## 실제 엔진의 25문항 종료

서로 다른 문제 묶음 25개의 응답이 모두 기록되는 즉시 `QUIZ_25` 종료를 예약한다. 마지막 정답/오답 피드백을 650ms 보여 준 뒤 과일 보너스를 기존 방식으로 한 번 정산하고 오답 복습·결과 화면으로 전환한다. `RUN.endReason`으로 TIME UP·최종 FINISH·25문항 종료 중 먼저 확정된 하나만 처리한다. 이미 종료한 뒤 문제를 다시 열거나 문에 진입할 수 없게 한다. 복습은 원래 응답 및 점수를 바꾸지 않는다.

**잠정 정책**: 25문항 종료는 정상 완료 화면으로 표시하되, 시간 보너스와 랭킹 자격은 감독 확정 전이므로 시간 보너스를 추가하지 않고 랭킹 등록을 보류한다. 점수/등록 화면에 정책 확인 중이라고 표시한다. 기존 FINISH의 `round(ceil(remainingMs/1000) × found/25)` 산식은 바꾸지 않았다. 예를 들어 25문항 발견·정답 점수 20·과일 점수 5·남은 시간 600초라면 25문항 잠정 점수는 25점이고, 동일 조건을 기존 FINISH 산식에 대입하면 시간 보너스 600점을 더한 625점이다. 이는 비교 예시이며 새 공식 랭킹이나 점수 정규화를 도입한 것이 아니다. 방 길이가 다른 결과는 통합 비교 정책을 별도 결정해야 한다.

## 시작 화면과 구름

지형·바닥·물리 좌표는 그대로 두고, Maker가 아닌 첫 지상 스테이지의 카메라 초기 구도만 월드 좌표 20px 위로 이동한다. 관찰한 2배 확대 화면에서는 바닥이 약 40 화면 px 아래에 보인다. 이후 기존 실루엣 안전 범위·상하 추적·동굴 카메라는 유지한다.

봄과 열대 배경의 구름 레이어에 기존 카메라 수평 패럴렉스를 유지한 채 초당 0.12/0.18 텍스처 px의 느린 이동을 더했다. 수직 패럴렉스와 지형은 바꾸지 않았고 배경 재생성 시 구름 진행 위상을 유지한다. 시작 위치와 시험 훅으로 이동한 높은 위치의 화면을 직접 확인하고 카메라 안전 범위·구름 수평 이동·수직 값·배경 재생성을 자동 검증했다. 모든 해상도·높이·기기·맵을 실제 플레이한 것은 아니다.
