# Phase 4D — 공용 기믹 엔진

사용자는 직접 전체 게임을 완주했다고 보고하고, 세부 미검증 항목을 남긴 채 4D 착수를 승인했다. 기존 사용자 보고와 에이전트가 직접 확인한 결과를 구분한다. 기준 `c89c94d998f9a7888e32e8e30ecbf0f6107603ea`; 4E와 기본 맵 콘텐츠 추가는 범위 밖이다.

## 공용 모델

`js/gimmicks/model.js`는 Phaser와 난수 호출 없이 월드 픽셀 좌표와 경과 시뮬레이션 밀리초를 받아 위치·상태·충돌 범위를 계산한다. 톱날의 축/거리/속도, 진자의 줄/진폭/속도/위상, 바람의 방향/세기/주기/활성 시간, 화염의 대기/예고/분출/종료를 검증한다. 입력 오류는 명시적으로 실패하며 정규화 결과는 JSON으로 왕복할 수 있다.

- PASS: `node --test verification/phase4d/model.test.mjs` — 모델 5개 (경계, 결정성, 충돌, 직렬화, RNG 미사용).
- NOT RUN: 아직 실제 게임 Scene 연결, Maker import, 브라우저 및 기존 회귀. 모델 단위 시험을 실제 기믹 완성으로 보고하지 않는다.

## 실제 Scene 연결과 원본 에셋

Maker 시험 맵의 `type: gimmick` 설정을 게임 Scene에 전달한다. 시즌 기본 맵에는 새 기믹을 배치하지 않는다. 톱날, 가시 공과 쇠사슬, 선풍기, 불꽃은 기존 Maker에 내장된 Pixel Adventure 원본 이미지를 그대로 사용하며 생성·합성 이미지는 사용하지 않는다. 불꽃은 불이 보이는 부분만 피해를 준다. 설정의 시뮬레이션 시간과 물리 충돌은 공용 모델에서 결정한다.

- **PASS:** 공용 모델 5건, Scene 어댑터 5건, 모듈 순서 2건. 정지·사망 중 기믹 시각 정지 및 자원 해제, 불꽃 활성·비활성·화면 밖, 바람 구역, 톱날·진자 충돌을 단위 시험했다.
- **PASS — 브라우저 유도 시험:** 독립 Maker 맵에서 네 원본 에셋 표시, 일시정지, 팬의 실제 수평 속도 변화, 두 해상도, 톱날 접촉 후 사망과 부활, 진자 접촉, 불꽃 예고 시 무피해와 분출 중 피해를 확인했다. [톱날](screenshots/saw.png), [진자](screenshots/pendulum.png), [선풍기](screenshots/fan.png), [불꽃](screenshots/flame.png).
- **PASS:** 배포 및 시험 빌드, 배포판 정적 검사, 원본 및 Phase 1 해시.
- **NOT RUN:** 네 기믹의 실기기·저프레임·각각의 자연 플레이 전수, 외부 Maker UI 편집, 실제 학교 환경. 실제 레벨 배치나 Maker 편집기 추가는 이 시험의 범위가 아니다.

- **PASS — 기존 회귀:** 기준 고정 입력 trace, 싱글 QR·버전과 실제 HTTP 응답, 유도 FINISH 63점·중복 정산·오답 복습, 기존 Maker 가져오기·맵 전환, 초원 자판기와 동굴 여섯 체크포인트.
