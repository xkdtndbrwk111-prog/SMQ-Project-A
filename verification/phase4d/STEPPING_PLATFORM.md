# 이어지는 벽돌 발판 시험

교사용 시험판에서 **이어지는 벽돌 발판 시험 코스**를 선택한다. A/D로 발판을 따라가고 필요할 때 마침표로 점프한다. 블록이 도착 지면에 닿으면 오른쪽으로 이동해 골인한다. 서 있기만 하면 뒤쪽 블록이 앞으로 옮겨질 때 발판에서 떨어질 수 있다. 가시에 떨어지면 Enter로 부활한다.

사용자가 선택한 Maker 원본 `Free/Traps/Blocks/Idle.png`를 자르지 않고 사용한다. 파일은 22×22px이며 둘레 3px이 투명해 실제 블록 그림은 16×16px이다. 원본을 2배 표시하고 그림과 별도로 32×32px 충돌체를 둔다. 시험 설정은 1초 동안 마지막 블록 하나가 나머지 블록 위 레이어를 미끄러져 앞으로 이동하며, 15칸 전진 후 역방향으로 돌아온다. 각 블록은 이동하는 동안 플레이어에게 속도를 전달하지 않는다. Maker 프로젝트의 `stepping_blocks` 설정에서 방향·이동 간격·왕복 거리를 보관한다. 시험 코스의 배치는 정규 사계절 맵에 포함하지 않는다.

- **PASS — 모델·단위 시험:** 다섯 블록의 순서·좌우 이동과 끝에서 반전, 중간 위치의 연속 보간, 상위 레이어, 정지 중 시간 보존, 자원 해제.
- **PASS — 브라우저 유도 시험:** 온전한 Maker 블록 그림과 다섯 충돌체, 하나만 연속 이동할 때 나머지 네 개는 고정, 가만히 서 있는 플레이어가 자동 이동하지 않음, 뒤쪽 블록이 미끄러져 떠난 뒤 실제 낙하를 확인했다. 시작 위치는 시험용으로 이동했다.
- **PASS — 키보드 자동화:** 교사용 시험 코스를 선택하고 정상 방향 키로 발판을 따라가 사망 없이 골인했다. 실제 교사의 손 조작과 구분한다.
- **PASS — 기존 보호:** 원본·Phase 1 해시, 정적 검사, 고정 입력 trace·QR·유도 FINISH 63점·오답 복습, 이동 발판·뗏목·스프링·무너지는 발판과 입력 단위 시험.
- **NOT RUN:** 교사 직접 플레이, 실기기·학교망 및 모든 속도/지형 조합. 후속 Maker 편집 UI는 이번 시험에 포함하지 않는다.
