# Phase 4D 교사용 통합 기믹 코스

## 시작과 기록

개발 저장소에서 `HOJA_TEST_PROBE=1 node tools/build_current.mjs`를 실행하고 `python3 -m http.server 18195 --bind 127.0.0.1 --directory dist-current-test`로 시험 서버를 연다. 같은 컴퓨터에서 `http://127.0.0.1:18195/teacher-review.html`을 열고 **신규 기믹 시험 코스 → 검수 시작 → 게임 안의 시작 버튼**을 선택한다. 다른 기기에서 쓰려면 실제 사설망 주소와 방화벽을 따로 확인해야 한다. 이 주소는 로컬 시험용이며 운영에 배포하지 않는다.

A/D로 이동, 쉼표로 달리기, 마침표로 점프한다. 위험 장치 앞의 평지에서 움직임을 보고 지나간다. 톱날과 진자는 적절한 때에 점프하거나 지나간다. 송풍기는 왼쪽 바람을 피하거나 맞서 이동한다. 불꽃은 점멸 예고 후 분출하고 다시 꺼진다. 진자가 지나갈 때 S를 누르면 앉아 피할 수 있다. 바람 구간에서는 점프하며 전진하고, 오른쪽의 **골인 →** 표시를 지나면 코스 통과가 기록된다. 사망 후 Enter로 처음부터 다시 시도한다. 화면의 검수 시작 버튼은 같은 설정으로 코스를 새로 시작한다. 게임 밖의 **검수 기록 저장**을 눌러 JSON을 내려받는다. `courseId`는 `phase4d-gimmick-course`, 완료 시 `outcome`은 `COURSE_FINISH`이며 사망 위치와 원인, 골인 이벤트가 기록된다.

## 코스 구성

독립 [Maker 프로젝트](gimmick-course.json)는 185×24 타일의 평평한 바닥이며, 시작 → 지면 톱날(20) → 공중 톱날(34) → 진자(49) → 지속 바람(71) → 간헐 바람(98) → 불꽃 발판(125) → 상승 바람(145) → 하강 바람(158) → 골인(180) 순서다. 좌표는 타일 단위다. 각 구간 사이에 평지가 있고 난수 호출은 없다. 코스와 골인 표시는 시험 빌드 전용이며 외부 Maker 편집 UI나 기존 계절 맵에 배치하지 않는다. 톱날·사슬·가시 공·팬·불꽃은 Maker에 이미 포함된 원본 스프라이트다. 글자는 시험 코스 안내다.
