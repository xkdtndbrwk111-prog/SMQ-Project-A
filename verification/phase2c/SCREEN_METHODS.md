# 화면 진단 메서드와 경계 계측

화면·카메라 진단 버튼 분리 후에도 Scene에 버튼 전용 전환 메서드와 300ms 경계 계측 타이머가 남아 있었다. 지형 청크 전환, 카메라 수동 줌, 경계 측정, 광원·컬링 비교의 메서드와 계측 캔버스·상태 패널을 시험 빌드로 옮겼다. Scene의 기본 자동 카메라, 지형 렌더, 동굴 컬링 및 화면 크기 조정은 유지한다.

시험 빌드에서 실제 컬링 버튼 왕복과 경계 진단 표시·숨김을 확인한다. 배포 정적 검사는 이 메서드와 계측 요소가 빠졌는지 확인한다. 지상 덮개, 기본 동굴 컬링, 고정 trace, 유도 63점·정산·복습·QR 네트워크를 재검증한다. 외부 Maker·Lab 통합은 NOT RUN이다.
