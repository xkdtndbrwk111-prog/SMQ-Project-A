# 지상 숨은 구덩이 덮개와 물가 경계

## 원인

지상 숨은 공간은 `createUnderground`에서 지형과 같은 흙 타일을 캔버스로 합성해 깊이 11.5에 배치한다. `createWaterBankForeground`는 물에 빠진 캐릭터를 가리기 위해 인접 지형 조각을 복사해 깊이 12.5에 배치한다. 두 영역이 겹치면 물가 전경의 원래 지형 외곽선이 덮개 위에 그려져 닫힌 공간의 흙 표면에 세로 선이 나타난다. 고정 시드 314159의 지상 맵에서도 두 전경 조각과 덮개가 겹치는 것을 확인했다.

## 변경

덮개 좌표 계산을 공유하고 물가 전경을 덮개와의 교차 경계에서 나눈다. 덮개가 보이는 동안 겹치는 조각만 덮개 뒤에 배치한다. 덮개가 완전히 사라지면 해당 조각은 원래 깊이 12.5로 돌아간다. 겹치지 않는 물가 전경은 계속 기존 깊이를 사용한다. 캐릭터, 물리 몸체, 맵 좌표, 바닥 높이와 점수는 변경하지 않는다.

## 검증

- PASS — 고정 시드에서 실제 게임 장면의 덮개가 불투명할 때 겹치는 물가 조각이 뒤에 있고, 나머지는 기존 깊이에 있는지 확인.
- PASS — 플레이어 위치 유도로 덮개를 열고 다시 닫으면서 겹친 물가의 기존 깊이 복구와 재가림 확인. 이 시험은 시험 빌드 전용 훅을 사용한다.
- PASS — 네 지상맵의 닫힌 덮개를 브라우저 화면으로 확인. 물가 경계가 겹친 열대 맵에서 기존 세로선이 나타나지 않았다.
- NOT RUN — 모든 시드·기기·브라우저와 자연 플레이를 통한 전체 맵 왕래.
