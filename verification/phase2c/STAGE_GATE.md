# 맵 강제 전환과 Maker 경계

`HOJA_V2_NEXT_STAGE`는 원래 숨겨진 단추에서 임의 맵 전환을 수행했고 Maker 프로젝트에도 같은 엔진의 여러 맵을 순환하는 경로로 쓰일 수 있었다. 일반 싱글의 숨은 단추와 무조건 전환은 제거했다. 배포 정본은 Maker 모드일 때만 기존 전환 API를 실행하며, Maker의 전환은 기존처럼 랭킹 시험 모드로 처리한다. 시험 빌드에는 일반 맵에서도 동작하는 전환 버튼과 기존 랭킹 방지 처리를 주입한다.

독립 시험은 일반 싱글에서 함수가 false를 반환하고 맵·랭킹 상태를 건드리지 않는지, Maker 모드에서 다음 맵 호출과 랭킹 시험 플래그가 유지되는지 확인한다. 실제 배포 교사 화면에서도 일반 싱글 호출이 거부됨을 검사한다. 시험 빌드에서는 동굴에서 시험 버튼을 눌러 첫 맵으로 전환한다. 외부 Maker·Lab 앱을 통한 통합은 NOT RUN이다.
