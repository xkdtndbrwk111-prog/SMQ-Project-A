# 뗏목 의존성과 검증

- 스테이지 적용이 `RAFTS`와 물 높이 데이터를 선택한다. Scene은 움직이는 발판 그룹을 먼저 생성하고 뗏목을 그 그룹에 추가한 뒤 플레이어·몬스터 충돌을 등록한다. 플레이어 충돌 콜백이 해당 뗏목의 `touchAt`을 갱신한다.
- 일시정지·타격 정지 처리 이후 움직이는 발판과 Maker 객체 다음에 갱신한다. 침수 시 몸체 충돌을 끄며 복귀 시 플레이어와 겹치지 않을 때 다시 켠다. 경고·물 튀김·음향은 Scene과 SFX를 사용한다. 스테이지가 바뀌면 Scene과 물리 그룹이 재생성된다.
- `js/rafts.js`는 Scene과 해당 스테이지 설정, 물 높이 함수와 음향을 전달받는다. 물 높이, 속도, 접촉 유예, 대기, 복귀 조건과 갱신 호출 순서를 유지한다.
- 고정 16ms 단위 시험에서 뗏목의 충돌 그룹 등록, 탑승 후 침수 및 충돌 해제, 탑승자가 떠난 뒤 복구와 스테이지 재생성을 확인했다. 브라우저 회귀는 별도 실행한다.
