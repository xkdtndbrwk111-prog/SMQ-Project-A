# 대화 미리보기와 Maker 이벤트

호자·나한상·혼합 대화 미리보기 버튼과 버튼 전용 나한상/혼합 예시 문구는 시험 빌드에서만 삽입한다. 이 버튼들의 기존 클릭 연결은 `tools/current-test-dialogue.mjs`에 보존한다. 배포판은 Maker 이벤트가 호출하는 `HOJA_EVENT_DIALOGUE_PREVIEW`, 종료·상태 API, 대화 화면과 Maker에서 전달한 문구 처리 및 기본 예시 경로를 유지한다.

실제 배포 교사 게임에서 Maker 형식의 대화 문구를 API로 전달해 열기와 종료를 확인했다. 시험 빌드에서는 미리보기 버튼을 실제로 눌러 대화가 열리고 종료되는지 확인했다. 외부 Maker·Lab 앱과의 전체 통합은 NOT RUN이다.
