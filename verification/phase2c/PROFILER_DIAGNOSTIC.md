# CPU 프로파일 진단 분리

기존 `HOJA_V050_PROFILE`는 숨은 `hojaCpuProfileBtn`으로 활성화할 수 있었고 Scene의 여러 메서드를 감싸 실행 시간을 기록했다. 일반 시작에서는 꺼져 있었다. 프로파일러 객체, Scene 메서드 래퍼, 버튼 연결과 결과 패널을 `tools/current-test-profiler.mjs` 및 시험 빌드 전용 UI로 옮겼다. 배포판에서 프로파일러 래퍼 없이 기존 Scene 메서드가 실행된다.

시험 빌드에 삽입된 코드는 이전 코드와 일치하며, 실제 브라우저에서 프로파일 버튼을 켜고 끄는 동작을 확인했다. 배포 정적 검사는 프로파일러 식별자와 버튼이 없는지 확인한다. 동굴 기본 컬링, 지상 덮개, 고정 trace와 정산·QR 회귀는 별도 실행한다. 장시간 성능 분석 및 외부 Maker·Lab 통합은 NOT RUN.
