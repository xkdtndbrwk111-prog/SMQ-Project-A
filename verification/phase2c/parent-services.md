# 교사·학생의 내장 카트리지와 iframe 서비스

기존 두 부모 스크립트의 같은 구현을 `web/current/js/parent-services.js`로 옮겼다. 교사와 학생 모두 인트로 입력 초기화 뒤, 단원 선택기 초기화 전에 같은 동기 스크립트를 실행한다. 페이지별 상태는 각 브라우저에서 따로 생성된다.

- `catalog`는 같은 서버에 있는 목록 요청을 공유하고, 실패하면 다음 호출에서 다시 읽는다. `rpc('GET')`은 목록에 등록된 단원 파일을 읽는다.
- `setSources`는 부모의 문제 유효성 검사 후 선택된 원본과 이름을 보관한다. 교사 QR과 학생 시작은 같은 선택 상태를 사용한다.
- iframe이 준비 메시지를 보내면 선택한 소스를 전달한다. 랭킹 요청은 현재 iframe 및 단일 카트리지와 대조한 뒤 시험판의 오프라인 응답을 반환한다.
- `node --test verification/phase2c/parent-services.test.mjs`는 로드 순서, 동시 요청과 실패 후 재시도, 목록·문항 조회, 선택값 전달, 프레임 확인과 오프라인 랭킹을 검사한다. 실제 교사·학생의 HTTP 응답은 기존 브라우저 하네스가 별도로 확인한다.
