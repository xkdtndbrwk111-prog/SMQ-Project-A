# 동굴 렌더 진단 전역 접근 격리

`HOJA_STEP134_DIAG`, `HOJA_STEP135_DIAG`, `HOJA_STEP136_DIAG`의 전역 등록은 카메라와 렌더 A/B 상태를 외부에서 바꾸는 진단 경로다. 기존 정본에서 전역 참조는 Scene의 스테이지 초기화 한 곳과 전역 등록뿐이었다. Scene은 같은 클로저의 객체를 직접 사용하고 세 전역은 시험 빌드에서만 등록하도록 옮겼다.

`HOJA_STEP136_DIAG.applyVisibility`는 기본 동굴 렌더 최적화에도 쓰이며, `HOJA_STEP135_DIAG`는 그 가시성 판정과 결합돼 있다. 따라서 내부 구현은 이 단계에서 유지했다. 전역 접근만 격리했으므로 내부 진단 코드 분리는 계속 필요하다. 시험 빌드에서 세 진단 API가 등록됨을 확인하고, 배포 정적 검사는 세 전역의 부재를 확인한다. 동굴 맵 진입과 시야 전환, 지상 덮개 회귀를 시험했다. 외부 Maker·Lab 연결은 NOT RUN.
