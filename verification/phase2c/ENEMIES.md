# 몬스터 공통 처리와 9종 행동

기존 arcade.html의 사양·리소스 등록·생성 루프·종류별 갱신 분기를 js/enemies로 옮겼다. system.js는 기존 순서로 생성, 프레임 진행, Maker 순찰, 렌더 위치 동기화와 이동 껍데기의 적 간 충돌을 처리한다. 종류별 파일은 몸체 크기, 텍스처와 원본 에셋 ID, 상태별 이동·행동을 소유한다. 각 정의가 공통 시스템에 등록된 뒤 Scene을 초기화한다. 플레이어와의 접촉 효과 및 재생성은 기존 Scene 경로로 돌아간다.

개별 시험에서 9종의 대표 상태 전이·속도·그림과 텍스처 등록 순서를 확인했다. 10/10 PASS. 배포·시험 빌드, 정적 검사 27개, 원본 및 기준판 PASS. 모든 상태 조합의 실제 플레이는 NOT RUN.
