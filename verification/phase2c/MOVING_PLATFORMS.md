# 움직이는 발판 의존성과 검증

- 스테이지 적용은 `MOVING_PLATFORMS`, `STAGE`, `THEME`을 선택한다. Scene 생성 시 발판 객체와 동적 물리 그룹을 만들고 같은 그룹에 뗏목을 더한다.
- Scene은 플레이어·몬스터와 그룹의 충돌 콜백을 등록한다. Maker 발판은 단방향 충돌과 이동 경로·스프라이트 규칙이 다르다. 앉기 상태의 머리 공간 판정과 적의 낭떠러지 판정도 이 그룹 또는 발판 배열을 읽는다.
- Scene update는 일시정지와 타격 정지 처리가 끝난 뒤 발판을 갱신하고, Maker 객체와 뗏목을 뒤이어 갱신한다. 충돌과 이벤트 등록·Scene 종료 및 스테이지 재생성은 Scene이 담당한다. 개별 발판은 스테이지 전환 후 다시 생성되며 별도의 점수·수집 기록이 없다.
- `js/moving-platforms.js`는 Scene, 현재 스테이지와 렌더 상태를 받아 기존 생성·속도·그림 동기화를 수행한다. Maker 이미지와 테마 상수는 팩터리 생성 시 주입한다.

고정 16ms 모듈 시험은 경계 반전과 그림 동기화, 스테이지 재생성, 왕복·반복 경로를 확인한다. Phaser 브라우저의 기준 trace와 실제 엔진 정산·입장 시험은 별도로 수행한다.
