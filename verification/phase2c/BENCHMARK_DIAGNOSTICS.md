# 화면 배율·지형 비교 진단 분리

`HOJA_V053_BENCH`, `HOJA_V055_BENCH`, `HOJA_V054_RENDER_AB`는 정지된 장면에서 배율, 지형 청크 또는 화면 요소를 비교하는 진단이며 숨은 버튼 네 개에서만 실행됐다. 게임 프레임에서는 이 객체를 호출하지 않았다. 기존 객체의 전체 코드와 Scene 버튼 연결은 `tools/current-test-benchmarks.mjs`로 옮기고 시험 빌드에서만 기존 클로저 위치에 삽입한다. 시험 버튼과 결과 영역도 시험 빌드에만 만든다. 실제 게임의 화면 배율 변경 함수 및 지형 렌더러는 그대로 사용한다.

배포 정적 검사는 벤치마크 전역과 결과 기록이 빠졌는지 확인한다. 브라우저 시험은 시험 빌드의 객체와 네 버튼 연결, 배율 수동 비교 버튼의 왕복 클릭을 확인했다. 고정 trace, 63점 정산·복습 및 독립 QR 네트워크도 PASS. 장시간 자동 벤치마크 전체 측정과 외부 Maker·Lab 연결은 NOT RUN.
