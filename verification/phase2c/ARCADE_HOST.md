# 부모 페이지와 아케이드의 메시지 경계

교사와 학생이 같은 iframe에 보내는 준비·시작·오류·랭킹 응답 메시지를 `web/current/js/arcade-host.js`로 분리했다. 부모 확인, 카트리지 이름 검증, 중복 시작 차단 및 미완료 요청의 타임아웃은 이 모듈이 소유한다. 실제 덱과 HUD를 설정하고 Phaser를 부팅하는 일은 엔진의 prepare/launch 콜백이 맡는다. 메인 클로저가 이전과 같은 위치에서 리스너를 등록하고 준비 메시지를 전송한다.

독립 시험은 다른 창의 메시지 무시, 실패 후 재시도, 단일 시작, 역순 랭킹 응답, 시간 초과와 늦은 응답을 다룬다. 독립 시험의 랭킹 응답은 메모리 안에서 발생한다. 실제 게임 경로는 기존 replay·settlement·network로 점검한다.
