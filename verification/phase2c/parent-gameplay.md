# 교사·학생의 아케이드 iframe 진입

두 부모 페이지의 `HOJA_GAMEPLAY` 구현을 공용 `web/current/js/parent-gameplay.js`로 옮겼다. 단원 정보 글꼴 맞춤은 부모에 남아 있다. 두 페이지에서 이 화면 초기화 직후, 아케이드 음향·이전 버튼 연결과 교사 또는 학생 전용 진입점에 앞서 같은 스크립트를 실행한다.

서비스의 `setSources`가 부모 카트리지 검사와 선택을 실행한다. 교사 모드 선택과 학생 시작은 이 모듈의 `launch`를 호출하고, 계절과 카트리지가 정해지면 `arcade.html`을 iframe에 연다. 게임 종료 메시지는 같은 iframe에서 온 경우에만 처리한다. 교사는 모드 선택으로, 학생은 재시작 화면으로 돌아간다. 문항별 응답과 정산은 iframe 엔진이 소유한다.

`parent-gameplay.test.mjs`는 실제 두 부모가 연결한 스크립트를 실행해 아케이드 실행·종료와 잘못된 모드·미선택 상태를 확인한다. `parent-services.test.mjs`는 실제 DOM 초기화 순서의 선행 조건과 iframe 메시지 전달을 따로 검사한다. 구간별 종합 검증은 기존 브라우저 회귀 하네스를 사용한다.
