# 교사·학생 부모 화면의 문제 풀이 전용 코드 제거

기준 `fc80cd1`에서 두 부모의 모드 선택과 학생 시작은 `HOJA_GAMEPLAY.launch('arcade', season)`을 호출한다. 이 함수는 다른 모드에서 즉시 반환했다. 해당 경계 밖에서 구형 풍선 게임의 HUD, 문항·결과 DOM, 전용 CSS, 캐릭터·몬스터 애니메이션, 정답 효과음, Space·클릭·리사이즈 리스너를 사용하는 코드는 없었다. 이 전용 경로와 두 페이지의 이전 시험 메타를 함께 제거했다.

교사 단원 목록과 학생 QR은 카트리지를 선택할 때 부모의 `setServerQuestions`를 호출한다. 이 검사의 예외 처리, 문제 묶음 선택과 난수 호출 순서, 25묶음 실행 조건은 게임 진입 경로에 남아 있다. 부모의 뒤로 가기와 상태 조회 형태, 모드 선택 미리보기 애니메이션 및 아케이드 iframe의 문항·결산·복습은 유지했다.

- 부모 단위 시험은 교사와 학생 각각에 대해 구형 진입 거부, 미선택·선택·초기화 후 아케이드 시작, iframe 종료 후 돌아갈 화면을 확인한다.
- 검증 명령은 `node --test verification/phase2c/parent-gameplay.test.mjs`다. 현재 배포·시험 빌드와 기존 Phase 2 브라우저 하네스를 함께 사용한다.
