### 싱글 QR 규칙
`play.html?m=s&c=<카트리지 id>&cv=<카트리지 버전>&gv=<게임 버전>&s=<시즌>`
- `m=s`가 아니면, 게임 버전(`gv`)이 지금 배포본과 다르면, 카트리지 버전(`cv`, 파일 내용의 SHA-256 앞 12자리)이 다르면 → 입장을 막고 **"선생님께 새 QR을 요청하세요"**.
- 게임 버전 = 교사·학생 페이지 + arcade.html 내용의 해시(이번 빌드 **950bf7f924**). 게임이나 카트리지가 바뀌면 옛 QR은 자동으로 막힌다.
- 학급 대결 QR은 Phase 3에서 다른 진입 경로로 만든다.
- 여러 단원을 섞은 게임은 결과는 보이지만 개인 랭킹 대상이 아니다(단일 카트리지만, 기존 규칙 유지).

## 5. 남은 일과 확인이 필요한 점
1. **태블릿 이동 조작이 없다.** 원본 아케이드에 화면 이동 버튼이 없다(키보드 전용, 교사 도구의 localhost 시험 연결만 있었음). 문제 고르기는 터치가 되지만 이동·점프는 키보드가 필요하다. 학생이 태블릿으로 할 경우 화면 조작 버튼을 만들지 결정이 필요하다.
2. **개인 오답 확인, 고른 보기·풀이 시간 기록**: 정책은 확정됐지만 이번 1B 목록에는 없어 구현하지 않았다. 다음 단계에서 진행.
3. **랭킹(B안)**: 새 Apps Script + Sheets 생성·배포는 별도 승인 후.
4. **학급 대결**: '준비 중' 표시만. Phase 3(Firebase, 비운영 별도 프로젝트).
5. 정리 대상(동작에는 영향 없음): 문제 풀이 모드 코드는 버튼만 빠지고 코드가 남아 있다. 개인 카트리지 화면 요소는 저장소 코드가 참조해 숨김 처리만 했다. 아케이드 안 시험용 버튼 묶음은 원본에서 이미 숨겨져 있다.
6. **사용자 의견: 바닥 지형이 너무 높게 느껴짐** → 맵 변경 단계(Phase 2 이후)에서 다룸.
7. QR의 시즌 값은 아케이드에 전달되지만 첫 맵은 원본처럼 항상 GRASSLAND로 시작한다.
