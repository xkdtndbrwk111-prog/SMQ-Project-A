# HOJA 학급 대결 격리 통합 시험판

기준 f23713e. 운영 서비스가 아닌 `demo-hoja-phase3a` Auth/Firestore 에뮬레이터와 같은 컴퓨터의 HTTP 어댑터로만 작동한다. 클라이언트 결과는 자체 보고이며 완전한 점수 위조 방지 기능은 없다. 운영 배포 및 실제 Firebase 연결은 하지 않았다. 에뮬레이터를 종료하면 방과 참여자는 사라진다. 학생은 계정이나 비밀번호를 입력하지 않는다.

## 실행

Node, Java 21 및 `verification/phase3b2`의 `npm ci`가 필요하다. Firebase 에뮬레이터가 이미 다운로드되어 있지 않으면 첫 실행에 인터넷이 필요하다. 기존 설치가 있으면 `HOJA_EMULATOR_CACHE`로 캐시 디렉터리를 지정할 수 있다.

```sh
export JAVA_HOME='/path/to/jdk'
verification/phase3c/run-class.sh
```

터미널에 표시되는 `교사 시험판` 주소를 교사 브라우저에서 연다. 이 주소의 열쇠는 교사 권한이므로 학생에게 공유하지 않는다. 카트리지와 시간을 정해 방을 만든 후 학생은 화면의 QR을 사용하고 이름을 입력한다. 교사는 A팀/B팀을 배정하고 시작한다. 학생은 시작 버튼을 눌러 기존 게임을 실행한다. 결과를 제출하면 복습한 뒤 자신의 결과를 볼 수 있으며 교사가 발표하기 전에는 팀 순위가 보이지 않는다.

기본 실행은 교사 컴퓨터의 사설망 IP를 자동 선택한다. 사설망 주소를 찾을 수 없을 때는 127.0.0.1로 실행되며 이 경우 같은 컴퓨터의 별도 브라우저에서만 열린다는 경고를 표시한다. 다른 사설망 IP를 직접 지정할 수도 있다. 예: `HOJA_CLASS_HOST=192.168.0.10 verification/phase3c/run-class.sh` (실제 IP를 입력). 같은 네트워크와 방화벽의 포트 8767 접근이 필요하다. 브라우저별 독립 세션이 필요하므로 한 컴퓨터에서 재현할 때는 서로 다른 브라우저 프로필 또는 시크릿 창을 사용한다. 실기기·학교망은 미검증이다.

게임을 새로고침하면 진행 상태는 복원되지 않고 학생에게 안내된다. 교사는 해당 학생의 '다시 시작 허용'을 선택할 수 있다. 결과 전송 중 연결이 끊기면 같은 요청을 재시도한다. 종료 시 미제출 학생은 점수 0으로 해당 팀의 평균 분모에 남으며, 교사는 결과 발표 전에 제외할 수 있다. 팀 순위는 방 안에서만 계산하며 평균 동점은 공동 순위다.

## 검증 및 한계

- 통합: 실제 Auth·Firestore 에뮬레이터와 교사 1/학생 3 독립 Chromium 컨텍스트에서 QR 주소 입장, 팀 배정, 900초 게임 시작, 새로고침·교사 재시작, 세 종류 종료, 제출, 팀 평균·발표 확인. 세 종료는 시험 빌드의 제어 기능으로 유도했고 자연 완주가 아니다. 게임 화면 캡처는 진단 버튼이 없는 배포 빌드에서 별도로 촬영했다.
- 게임 시간과 점수: 기본 900초, 기본 경계 200/100초, 교사 설정 300~1800초와 비례 경계. 25문항 정상 종료는 FINISH와 같은 시간 보너스 `round(ceil(remainingMs/1000)*found/25)` 적용. 기존 600초 기준 기록은 수정하지 않았다.
- 에뮬레이터 격리, 권한, 중복 제출·마감 경합, 버전 오류는 별도 기존 에뮬레이터 시험으로 검증한다. 싱글은 별도 코드 경로이며 Firebase 요청이 없다.
- NOT RUN: 실제 학생과 실기기/태블릿 입력, 전자칠판, 학교망 및 다수 단말 부하, 장시간 실제 900초 플레이, 자연 완주, 운영 호스팅·Firebase·GAS, 외부 Maker/Lab 전체 연동. QR 이미지는 생성되고 같은 주소로 브라우저 접속을 확인했으며 물리 카메라 스캔은 하지 않았다. Phaser CDN 접근이 필요하다.

통합 자동 시험: `HOJA_CLASS_BUILD=test verification/phase3c/run-class.sh`를 실행한 뒤 출력된 교사 주소를 `HOJA_TEACHER_URL`로 지정하여 `node verification/phase3c/browser-test.mjs` 실행. 시험 빌드 제어 도구는 배포 빌드에는 없다.
