# 교사용 직접 플레이 검수 — 시험 빌드 전용

## 시작

프로젝트 폴더에서 다음을 실행하고 같은 컴퓨터의 브라우저로 `http://127.0.0.1:18193/teacher-review.html`을 연다.

```sh
HOJA_TEST_PROBE=1 node tools/build_current.mjs
python3 -m http.server 18193 --bind 127.0.0.1 --directory dist-current-test
```

1. **전체 게임 처음부터** 또는 **스테이지별 검수**를 고른다. 스테이지별은 초원·가을·열대·겨울·동굴 중 시작점을 고른다.
2. 시드 0~4294967295를 입력하고 시작한다. 같은 시드는 같은 지형을 재생성한다. 문제 순서는 일반 게임의 기존 무작위 출제 방식을 따른다.
3. 게임 화면에서 **시작**을 눌러 직접 플레이한다. A/D 이동, W 위·문, S 아래·토관, 쉼표 달리기, 마침표 점프, Enter 확인·부활, H 도움말이다. 내장 시험 카트리지 25개 문제 묶음을 사용한다.
4. 이상한 위치에 도달하면 메모를 쓰고 **현재 위치 메모 추가**를 누른다. 시드·스테이지·좌표, 사망 이유와 부활점이 기록된다. 타이머는 메모 중에도 기존 게임 규칙대로 흐른다.
5. **검수 기록 저장**으로 JSON을 이 컴퓨터에 내려받는다. **검수 중단** 후에도 저장할 수 있다. 다시 시작하면 기존 기록이 교체되므로 먼저 저장한다.

시험 빌드의 `teacher-review-arcade.html`은 운영형 원본에서 별도로 생성한다. 시드와 최초 스테이지 설정, 읽기 전용 상태/사망/문 이벤트만 추가하고, 기존 자동 회귀용 강제 이동·무적·정산·스테이지 전환 도구를 포함하지 않는다. 검수 페이지와 전용 게임은 배포형 빌드에 들어가지 않는다. 일반 시험 빌드의 `arcade.html`과 기존 자동 회귀 훅은 그대로 유지한다.

## 결과 해석

- 전체 게임 시작과 선택 스테이지 시작은 기록에 서로 다른 라벨로 저장된다. 동굴 선택은 지상 자연 진입이 아니다.
- 시드 지정과 스테이지 선택은 기록에 시험 개입으로 남는다. 문을 통과한 시점, 사망 원인, 체크포인트 변경과 교사 메모도 기록한다. 종료하지 못하면 `INCOMPLETE`다.
- 실제 교사가 정상 키 입력으로 직접 플레이한 결과만 교사 수동 검수다. 자동 브라우저 테스트와 위치 강제 이동 테스트는 이에 포함하지 않는다. 도구가 통과해도 Phase 4C 자연 완주가 완료되는 것은 아니다.
- 기록에는 학생 개인정보가 필요 없으며 다운로드는 브라우저 로컬 저장이다. 화면을 다시 열기 전 기록을 보관한다.

## 검증

`node --test verification/phase4c/teacher-review.test.mjs`는 교사용 5개 시작 위치, 시드 0 및 재현, 실제 브라우저 키 입력, 메모·JSON, 전체/선택 라벨, 배포형 URL 404 및 API 비노출을 확인한다. [검수 화면](screenshots/teacher-review/play.png).

실제 교사의 전체 자연 완주, 학교망·실기기 사용은 **NOT RUN**. 결과를 감독자가 검토하기 전 Phase 4C 종료 및 4D 진입은 보류한다.

### 실행 결과

- **PASS:** 운영형 빌드 정적 검사 및 브라우저에서 검수 URL 404, 검수/일반 시험 조작 API 미노출. 시험 빌드 교사용 화면의 다섯 시작 스테이지, 시드 0 재시작의 지형 일치, 실제 브라우저 키 이동, 메모와 JSON 다운로드, 전체/선택 결과 라벨.
- **PASS:** 선택 스테이지 출구 기록은 테스트 서버가 일시적으로 응답에 주입한 별도 유도 도구로 실제 문 이벤트를 호출해 확인했다. 해당 주입 코드는 생성된 교사용·배포용 게임에 포함되지 않으며 자연 완주가 아니다.
- **PASS:** 기존 Phase 4A~4C 시험, 원본·Phase 1 해시, 30개 기믹/적/입력 등 단위 시험, 결정적 trace, QR·싱글 네트워크, 유도 FINISH 63점·중복 정산·오답 복습, 지상·동굴 체크포인트 및 토관, 3명 개인전 브라우저 통합, 격리 데모 에뮬레이터 21개 시험. 클래스 에뮬레이터는 임시 복사본에서 Firestore 18081·허브 4401을 사용하고 운영 우회 차단을 유지했다.
- **NOT RUN:** 실제 교사가 수행한 사계절/동굴 전체 자연 완주, 실제 학교망·교실 기기 및 다수 물리 기기 동시 시험. 기존 자연 완주 기록을 PASS로 바꾸지 않는다.
