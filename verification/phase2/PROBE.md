# Phase 2A — 시험 빌드의 수동 경로 확인

기준판 83e8ac1에서 만든 `dist-test`에만 표시되는 TEST ONLY 제어를 사용했다. 시작은 교사 화면에서 시험 A 카트리지 → 혼자 아케이드 → 바로 플레이. 이 제어는 대상 처리를 직접 유도하므로 자연 이동 경로의 도달 가능성이나 실제 600초 경과를 증명하지 않는다. 배포본에는 포함하지 않는다.

```
HOJA_TEST_PROBE=1 node tools/build_web.mjs
python3 -m http.server 8081 --bind 127.0.0.1 --directory dist-test
```

- PASS: 쓰러짐 유도 → 사망 대화상자 → Space는 대화상자를 닫지 않음 → Enter로 복귀. 테스트 훅이 낙하를 직접 유도했으며 자연 낙하 경로는 확인하지 않았다.
- PASS: 문제 열기로 문제를 연 뒤 오답 선택 → 2초 후 종료 유도 → 결산에서 1문항·정답 0·오답 1·0점 → Enter로 오답 풀이 → 정답 → 결산에서 원래 0점과 정답 0·오답 1 유지 → 랭킹 화면의 시간 종료 및 서버 등록 대상 아님 표시.
- PASS: 배포본 `dist`에 대한 기존 27개 정적 검사와 Phase 1 기준 해시 비교. 테스트 빌드 생성 후에도 배포본 기준 해시는 일치.
- NOT RUN: 모든 키의 쓰러짐 화면 차단, 자연 낙하, 모든 문항·복습 반복, 점수와 과일이 있는 중복 정산, 자연 600초 및 5맵 완주, 동일 시드·프레임 입력 재현. 위 수동 점검은 자동 회귀 하네스의 대체물이 아니다.
