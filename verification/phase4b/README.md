# Phase 4B — 계절 장식과 세 부활점

기준 `8852a2b7dddc8e9fd297ef2afdf933bec3332aa6`. 정본은 `web/current/`, 배포판 `node tools/build_current.mjs`, 별도 시험판 `HOJA_TEST_PROBE=1 node tools/build_current.mjs`.

## 구현

- `web/current/js/world/stage-decor.js`: 생성 완료된 실제 지면 사각형에 계절 장식을 배치한다. 출제·기존 장식·꽃·동굴·물·문 주변을 피하고, 적이 밀집한 곳은 생략한다. 장식 전용 위치 해시만 사용하며 기존 맵 조각과 RNG를 수정하지 않는다. 반전된 조각도 조립된 실제 지형을 다시 읽는다.
- 계절에 필요한 기존 카탈로그 이미지만 해당 장면에서 불러온다. 가로등과 자판기는 다른 배경 장식 앞에 그리며 서로 겹치지 않게 하고, 공중 발판과 기존 구조물에 겹치지 않는 위치를 찾는다. 물리 충돌체는 추가하지 않는다. 지연 로딩이며 원본 파일을 새로 복제하지 않았다. 16×16 원본을 주로 2배, 집과 벤치 등 큰 원본은 1배로 그린다. 기존 `tree`/`small`, 공중 발판과 동굴 렌더러는 유지한다.
- 자판기는 네 지상 맵에 각각 한 개, 물과 동굴을 피한 중간선 근처의 실제 바닥에 표시한다. 왼쪽 진입·오른쪽 문 진입·중간선 통과 중 가장 최근에 활성화된 시작점/도착점/중간점 세 위치 중 하나를 사용한다. 양방향으로 가상 세로선을 넘어도 중간점이 활성화된다. 중간에서는 자판기의 불빛과 흔들림 및 메시지로 표시하고, 다른 지상 맵 문으로 입장하면 효과를 끈다. 동굴에서 같은 지상 맵으로 돌아오면 이전 부활점을 유지한다.
- 물의 수면·충돌·떨어지는 규칙은 변경하지 않았다. 장식은 물리 몸체가 없다. `arcade.html`의 기존 부활 및 물 사망 경로에만 체크포인트 선택을 연결했다. Maker와 독립 동굴의 부활 정책은 기존대로 둔다.
