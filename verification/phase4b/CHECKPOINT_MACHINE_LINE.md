# 지상 자판기 체크포인트 판정 위치 수정

초원 시드 314159에서 시작·끝의 산술 중앙은 x=2280이었지만 안전한 지면에 배치된 자판기는 x=3088이었다. 기존에는 중앙의 가상선을 지나갈 때 저장하면서 부활 위치는 자판기로 지정해 알림과 실제 보이는 저장점이 808px 떨어졌다.

안전한 자판기 후보는 기존처럼 맵 중앙에서 가장 가까운 바닥을 찾는다. 초원에서만 저장을 발동하는 가상 세로선을 그 자판기의 x 좌표로 옮겼다. 가을·열대·겨울의 저장 판정선은 유지한다. 따라서 호자가 직접 자판기에 접촉하지 않아도 해당 x를 위아래 어느 높이에서든 양방향으로 통과하면 중간 체크포인트가 활성화된다. 세 지상 체크포인트의 개수 및 동굴 체크포인트, 지면·적·타이머·게임 난수는 바꾸지 않았다.

`checkpoint-line.test.mjs`는 시드 314159의 기존 중앙 통과 시 저장이 발생하지 않는지, 자판기 x에서 양방향으로 저장되는지, 조명 활성화와 실제 사망 후 Enter 부활 위치가 자판기인지 브라우저에서 확인한다. 위치 유도 시험이며 자연 플레이 완주가 아니다. 여러 시드의 실제 생성 맵에 대한 안전한 자판기 배치 검사는 유지한다.

열대 짧은 난간은 원본 난간의 한 조각만 잘라 사용해 끊긴 모양이었다. 기존 에셋의 온전한 48×16 영역으로 수정했으며 충돌이나 지형은 변경하지 않았다. 장식 배치는 기존 결정적 위치 계산과 충돌 회피를 사용한다.

## 검증 결과

- PASS: 시드 314159 초원에서 이전 중앙 통과 시 저장되지 않고 자판기 세로선을 양방향으로 넘을 때 저장·점등되며, 실제 사망 후 Enter로 자판기 위치에 부활한다. 위치 유도 시험이다.
- PASS: 18개 생성 시드의 배치 검사, 초원 외 세 지상 테마의 기존 중앙 판정선 유지, 사계절 체크포인트와 토관 왕복 및 동굴 여섯 체크포인트 회귀, 기존 결정적 trace·QR/네트워크·FINISH 정산, 원본 및 Phase 1 무결성, 배포형 정적 검사.
- PASS: 열대 난간 원본 영역 검사와 실제 장면의 [수정 화면](screenshots/checkpoint-fix/tropical-rail.png). 짧은 조각 대신 완전한 난간의 폭을 적용하므로 일부 장식은 겹침 방지 규칙에 따라 재배치되거나 생략될 수 있다.
