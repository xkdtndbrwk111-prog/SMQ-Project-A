# Phase 4E-2 조각 시스템 검증과 감독 시험 안내

[작업 이슈 #10](https://github.com/xkdtndbrwk111-prog/SMQ-Project-A/issues/10) · [규격과 제작 안내](../../tools/maker_fragments/README.md) · [스키마](../../tools/maker_fragments/fragment.schema.json)

## 감독 시험

저장소 루트에서 실행한다. 기존 원본 Maker는 변경하지 않는다.

```sh
node tools/build_current.mjs
HOJA_TEST_PROBE=1 node tools/build_current.mjs
python3 -m http.server 18210 --bind 127.0.0.1 --directory dist-current-test
```

브라우저에서 `http://127.0.0.1:18210/maker-compat.html`을 연다. **3조각 시험 맵**을 누르면 안전 시작 → 공중 톱날 → 송풍기·집 3개 조각이 64×24칸으로 합쳐져 편집기에 표시된다. **플레이 테스트**를 누르고 팝업을 허용한다. A/D 이동, 쉼표 달리기, 마침표 점프, 집 앞에서 W로 들어간다. 전체 수동 완주는 아직 확인되지 않았다.

`조각 JSON 열기`에서 여러 파일을 선택하면 파일명 순으로 연결한다. `맵을 조각으로 저장`은 현재 맵 전체를 하나의 조각으로 저장하며 왼쪽과 오른쪽에 지면이 있어야 한다. 편집 후 다시 저장하고 다시 불러와 Play Test를 반복할 수 있다. 연결 조건이 맞지 않으면 기존 편집 내용을 보존하고 오류를 보여 준다. 32칸 미만 단일 조각은 우측에 빈 맵 공간만 추가한다.

## 조각 목록

- `practice-0`, `practice-4`, `practice-3`: 기존 4D 기믹 코스에서 발췌한 검수용 3조각. 시작 문과 집은 검수판용으로 추가했다.
- `practice-1`, `practice-2`, `practice-3`: 같은 원본의 지상 톱날·공중 톱날·진자·송풍기를 포함한 별도 조합. `practice-compiled.json`은 이 조합의 6101 출력이다.
- `stepping-course`: 기존 4D 가시/절벽과 이어지는 벽돌 발판 코스의 보존 복사본.
- `monster`, `moving`: Maker 기존 예제의 몬스터·이벤트와 이동 발판/경로를 발췌했다.
- `cave-checkpoints`: 기존 Maker 브라우저 시험의 동굴 지면·문·자판기 구간에서 발췌했다.
- `pipe-pair`: 검증을 위해 두 토관을 명시적으로 연결한 신규 시험 데이터다. 기존 solid 토관을 자동 변환하지 않았다.
- `invalid-height`: 고의적인 연결 조건 오류. `showcase-compiled.json`은 검수용 3조각의 6101 출력이다.

## 결과

- **PASS — 조각 단위:** 스키마·검증기, 단일 저장/불러오기, 지면 접합 조건, 동일 입력/시드 반복, 원본 불변, 확장 필드, ID 충돌, 상대 좌표·적/발판 순찰 경로, 토관 및 이벤트 참조, solid 자동 변환 금지, 구형/신규 톱날 구별. 톱날·진자·화염·이어지는 발판의 조각 경계 이탈은 경고한다. `fragments.test.mjs`.
- **PASS — 브라우저 유도:** Maker 조각 불러오기·저장/재불러오기, 잘못된 파일 거부와 기존 상태 보존, 3조각 미리보기, 실제 게임 로드 및 수정 후 반복 전송, 새 기믹·이어지는 발판 생성. 토관 왕복과 동굴 체크포인트·부활은 위치를 시험용으로 이동한 뒤 실제 키를 사용하는 유도 시험이다. `fragments-browser.test.mjs`.
- **PASS — 키보드 자동 조작:** 검수용 3조각에서 위치 강제 이동 없이 점프와 두 접합부를 통과했다(관측 최대 x≈554~562). 사람의 플레이나 전체 완주가 아니다. `fragments-natural.test.mjs`.
- **FAIL — 기존 난도 조합 자동 시도:** `practice-1/2/3`의 지상 톱날에서 여러 차례 x≈439~490에 사망했고 한 차례 첫 경계를 지난 x≈564에서 중단했다. 검수용 코스는 별도의 기존 안전 구간으로 구성했다. 원본 지형·기믹은 변경하지 않았다.
- **PASS — 기존 회귀:** 원본 Maker 3개 및 Phase 1 해시, 정적 검사, 구형/신규 톱날, 9종 몬스터 단위, 기존 입력·물리·이동/무너짐 발판·뗏목·스프링·지면, 사계절 배경, 지상 저장점, 실제 Maker 토관·집·동굴과 반복 전송, 25문항 종료, 싱글 QR 및 네트워크, 고정 입력 trace, 유도 FINISH 63점·중복 정산·오답 복습.
- **PASS — 개인전 격리 네트워크:** 기존 18080 프로세스를 유지하고 별도 임시 복사본의 demo 프로젝트와 Firestore 18081, Auth 19098, hub 4401, 시험 서버 18767을 사용했다. 교사 1명·학생 3개 독립 브라우저에서 입장·독립 게임·중간 발표·응답 분석·종료, 20/25/30명 가상 배치를 확인했다. 종료는 시험 제어로 유도했으며 실제 학교망·30대 부하는 아니다.
- **PASS — 빌드 분리:** 조각 편집기·컴파일러·시범 JSON은 `dist-current-test`에만 포함되고 `dist-current`에는 없다.
- **NOT RUN:** 감독/교사의 직접 플레이와 3조각 전체 자연 완주, 컴파일된 절벽·점프 구간 자연 통과, 컴파일된 몬스터·이동 발판의 전체 실제 플레이, 교사/학생 실제 기기 및 학교망. 사계절 전체와 9종 몬스터의 자연 플레이를 새로 완주했다고 주장하지 않는다.

시험 과정에서 로컬 서버 생성 권한이 없어 브라우저 시험 몇 개가 시작되지 않았으나 적절한 환경에서 단독 재실행해 통과했다. 기존 Maker 통합 시험은 한 차례 장면 시작 대기 시간 초과 후 단독 재실행 PASS였다. 원본 해시 검사는 처음 잘못된 작업 경로에서 파일을 찾지 못했고 해당 디렉터리에서 재실행 PASS였다.

## 지원 범위와 남은 일

현재는 **같은 테마, 수평 순서, 일치하는 지면 접점**만 합친다. 높이가 다른 접점이나 서로 다른 테마는 명확히 거부하며 자동 보정하지 않는다. 좌우 반전·수직 연결·절벽 자동 생성·조각 라이브러리 UI·임의의 미지 참조 변환은 미구현이다. 알려진 `targetMapId`/`targetPortalId`, `eventId`/`triggerId`/`objectId`, `patrol.waypoints`만 변환한다. 알 수 없는 필드는 조각 스냅샷에 보존하지만 그 의미나 좌표를 추측하지 않는다. 동굴 조각은 별도 동굴 테마 맵으로만 컴파일하며, 지상과 동굴을 단일 맵으로 합치지 않는다.

Phase 4E-2 전체 감독 검수는 미완료이며 Phase 4F, 운영 배포 및 main 병합은 하지 않았다.
