# Maker 기믹과 맵 연결 시험판

기준 `accd223a135ef4fc8a6c1f83f11ac89e61107654`. V0.61 원본은 수정하지 않고 `tools/maker_compat/maker.html`을 확장한다. 운영 배포와 main 병합은 하지 않는다.

## 사용

`HOJA_TEST_PROBE=1 node tools/build_current.mjs` 후 `python3 -m http.server 18210 --bind 127.0.0.1 --directory dist-current-test`를 실행하고 `http://127.0.0.1:18210/maker-compat.html`을 연다. 팝업을 허용한다. 장치 팔레트에서 원하는 항목을 선택하고 맵에 배치한 뒤 오른쪽에서 값을 정한다. 프로젝트는 JSON 저장·불러오기로 보존한다.

맵 연결 화면은 맵 이름 옆에 테마를 표시하고, 아래 미니맵에서 문·외부 연결 토관·집의 실제 위치를 점으로 표시한다. 점을 길게 누른 뒤 다른 점을 클릭하거나 드래그하여 연결한다. 점을 오른쪽 클릭하거나 선택 후 Delete를 누르면 연결을 해제할 수 있다. 맵 카드의 **맵 열기**로 해당 맵을 편집한다. PASS: 실제 브라우저에서 미니맵 위치·테마·점 연결과 해제·줌·맵 열기, 기존 토관과 맵 이동을 확인했다. 교사 직접 검수는 별도다.

- 새 톱날: 축, 거리, 속도, 반지름, 지면에 묻기. 기존 V0.61 톱날은 그대로 별도다.
- 진자: 줄 길이·진폭·속도·공 크기.
- 송풍기: 네 방향·세기·작동 주기/시간. 방향을 가로/세로로 바꾸면 범위의 가로·세로도 바뀐다.
- 불꽃 플랫폼: 길이와 대기/예고/분출/종료 시간. 기존의 밟을 수 있는 발판과 불꽃 표시 및 피해를 재사용한다.
- 이어지는 벽돌 발판: 자동/탑승 후 출발, 방향, 벽돌 수, 속도, 직선 왕복 거리. 선택적으로 `0,0; 1,0; 2,0; 2,1; ...` 형식의 **서로 인접한 칸 좌표**를 입력해 경로를 정한다. 시작점은 `0,0`, 경로 길이는 벽돌 수보다 길어야 한다. 맵 위에도 경로를 표시한다.
- 낙하 가시 얼굴: 아래에 플레이어가 있으면 빠르게 내려와 지면·발판·토관에 닿아 멈추고 잠시 뒤 올라간다. 감지·낙하 거리, 낙하·복귀 속도와 대기 시간을 조정한다. 충돌 시 기존 사망 처리를 사용한다. Pixel Adventure 원본 머리·충돌 이미지를 사용한다.
- 원본 가시를 새로 놓으면 기본 피해 속성으로 배치한다. 의미를 확정하기 어려운 다른 원본 에셋은 종전처럼 그림으로 남긴다. 이전 저장 파일의 속성은 자동 변환하지 않는다.

## 문·집·토관 노드

장치에서 시작 문, 도착 집, 자판기 체크포인트, 토관을 놓는다. 시작 문은 시작 위치, 자판기는 접근 시 알림과 부활 위치, 연결하지 않은 집은 W키 클리어 및 기존 정산에 사용한다. 자판기는 충돌체가 없으며 동굴에서는 광원을 사용한다.

토관을 선택하고 머리의 ↻를 눌러 네 방향으로 회전하거나 몸통 끝의 ↔를 드래그해 길이를 조절한다. 기존 속성창에서도 방향과 **전체 길이**를 바꾸거나 **몸통 그리기** 버튼을 눌러 몸통의 끝까지 드래그한다. 원본 토관 머리를 그대로 사용하고, 원본 맨 아래의 32×1 픽셀을 16줄 이어 만든 32×16 몸통을 반복한다. 머리와 몸통 사이 이음매와 짧은 가로 무늬는 반복하지 않는다. 몸통에도 충돌체가 있다. 방향과 진입 키는 위 S, 아래 W, 왼쪽 D, 오른쪽 A다.

`맵 연결 노드`의 큰 캔버스에서 맵 이름을 드래그해 이동한다. 맵에 배치된 문·토관·집을 실제 왼쪽부터 순서대로 표시하고 각 지점 아래에 원을 하나씩 둔다. 출발 원을 길게 누른 뒤 도착 원을 클릭하면 연결되며 Esc로 취소한다. 양방향 연결이 기본이고 기존 연결은 덮어쓰지 않는다. 연결선은 맵 이동을 따라간다. 맵 내부 연결 토관은 제외하고 외부 연결 또는 연결 대기 토관을 표시한다. 확대 버튼과 터치패드 핀치 방식의 확대·축소 및 스크롤을 지원한다. 연결된 집은 해당 목적지로 이동하고 연결하지 않은 집은 클리어한다. 동굴 테마의 **Maker 맵**도 연결할 수 있다. 기존 시즌 게임의 자동 생성 4×4 동굴을 Maker에 자동으로 가져오거나 연결하는 기능은 아직 제공하지 않는다.

각 위치는 서 있을 수 있는 지면과 겹치지 않게 배치해야 한다. 에셋에 의미를 판단하기 어려운 것은 자동 변환하지 않으며 구형 프로젝트의 `solid` 토관도 그대로 보존한다.
