# Maker 이벤트 대사

이벤트 영역을 선택한 뒤 대사를 한 줄에 하나씩 입력한다. `호(2)-놀랐어!`처럼 괄호 안에 표정 번호 1~10을 쓰고, `호-안녕!`처럼 생략하면 1번이다. 이전 `호자|안녕!` 형식도 읽는다. 본문 안의 하이픈은 대사로 보존한다.

| 기호 | 인물 |
| --- | --- |
| 호 | 호자 |
| 나 | 나한상 |
| 수 | 수막새 |
| 칠 | 칠지도 장로 |
| 무 | 무령왕 |
| 반 | 반가사유상 |
| 광 | 광개토대왕 |

기존 호자·나한상 이미지를 유지하고, 다른 다섯 인물의 10표정씩 50개 이미지는 보존 원본 `legacy/decoded/team_portraits.json`에서 추출했다. 50개 원본 SHA-256 일치 및 게임 내 일곱 인물 표시를 브라우저에서 확인했다. 이미지는 해당 인물의 대사가 표시될 때만 요청한다. 실제 교사 제작 맵 및 학교 기기 검수는 NOT RUN이다.
