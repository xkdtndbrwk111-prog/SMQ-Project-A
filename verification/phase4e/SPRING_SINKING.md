# 원본 스프링과 내려가는 발판

- 스프링은 Maker의 Pixel Adventure 원본 대기 그림과 점프 8프레임을 사용한다. 기존 스프링 위치·충돌 범위·점프 힘과 입력 규칙은 바꾸지 않는다. 작동 그림은 약 400ms 동안 재생한다. 에셋은 스프링이 있는 스테이지만 불러온다.
- Maker 지형 팔레트에 `내려가는 발판`을 추가했다. 호자가 올라서면 초당 32px씩 최대 96px 내려가고, 내리면 초당 48px로 원위치에 돌아온다. 속성과 최대 거리는 변경할 수 있다. 아래 지형에 닿으면 더 내려가지 않는다. 원본 낙하 발판의 작동 애니메이션을 사용하며 뗏목과 별개다.
- 예전 맵의 `무너지는 발판`은 기존에 작동하던 흔들림·소멸·복구 동작을 보존한다. 새 발판은 다른 파츠이므로 기존 JSON이 자동으로 바뀌지 않는다.
- PASS: Chrome에서 실제 키 입력으로 탑승·하강·지형에 의한 정지·내린 뒤 복귀를 확인했고, 원본 스프링 대기·작동 그림 및 기존 점프 호출을 확인했다. 기존 발판·스프링 단위 시험, 배포 정적 검사. 수동 교사 검수와 전체 자연 플레이는 NOT RUN.
- 원본 그림은 기존 Maker에 들어 있던 `Free/Traps/Trampoline`과 `Free/Traps/Falling Platforms` 에셋을 그대로 사용한다.
