# Maker 선택 맵 플레이 테스트

- 예제 맵의 두 토관은 목적지가 이미 있으므로 새로 생성하는 예제에서 연결 토관으로 설정한다. 기존 저장 파일의 solid 토관은 자동 변환하지 않는다. 예전 예제의 두 토관 연결이 남아 있는 경우 사용자가 검사 영역의 복구 버튼을 눌러 명시적으로 수정할 수 있으며 실행 취소가 가능하다.
- 편집기 검사는 현재 선택한 맵을 대상으로 한다. 해당 맵의 연결 목적지는 다른 맵에서도 확인한다. 새 프로젝트와 새 맵은 서로 다르다.
- 플레이 테스트는 선택한 맵과 그 맵에서 연결을 따라 갈 수 있는 맵을 사본으로 전달한다. 원본 맵 순서나 프로젝트 데이터는 변경하지 않으며 기존 메시지에서 ID를 생략하면 기존처럼 첫 맵으로 시작한다. 조각 독립 시험은 그 조각의 맵을 시작한다.
- 시험 전용 게임 창은 장면이 준비될 때까지 준비 화면을 표시해 기본 맵이 잠시 보이지 않게 한다.
- PASS: 실제 브라우저에서 예제 검사, 빈 맵 선택·플레이, 기존 맵 보존, 이전 예제 오류에 대한 명시적 복구, 재실행 및 준비 화면. 기존 파일·메시지 호환성 별도 시험.
- NOT RUN: 교사 직접 시험 및 학교 실기기.

## 맵 경계 밖 지형과 준비 화면 (2026-11-25)

- 원인: 선택한 맵의 지형 일부가 맵 크기를 넘었지만 편집기 검사에는 표시되지 않았고, 게임의 가져오기 검증이 이를 거부한 뒤 준비 화면에 오류가 표시되지 않았다.
- 처리: 편집기는 맵 내부만 그린다. 게임은 프로젝트 사본에서 지형을 맵 경계로 잘라 적용하며, 완전히 밖에 있는 지형은 제외한다. 저장된 원본 좌표는 변경하지 않는다. 토관·스프링 등 개체는 기능을 임의로 변형하지 않고 기존 경계 검증을 유지한다. 가져오기 실패 시 게임 화면에 원인을 표시한다.
- PASS: 실제 작성 맵의 저장 사본으로 선택 맵 시작 및 원본 보존을 별도 브라우저에서 확인. 네 방향 경계, 맵 밖 지형, 원본 보존, 개체 오류 안내 자동 시험. 기존 선택 맵 재생 시험과 Phase 1 기준 해시 확인.
- NOT RUN: 사용자가 열어 둔 편집기 탭에서의 직접 재실행 및 교사 육안 검수. 기존 탭은 저장 내용을 보존하기 위해 새로 고치지 않았다.
