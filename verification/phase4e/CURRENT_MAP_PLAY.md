# Maker 선택 맵 플레이 테스트

- 예제 맵의 두 토관은 목적지가 이미 있으므로 새로 생성하는 예제에서 연결 토관으로 설정한다. 기존 저장 파일의 solid 토관은 자동 변환하지 않는다. 예전 예제의 두 토관 연결이 남아 있는 경우 사용자가 검사 영역의 복구 버튼을 눌러 명시적으로 수정할 수 있으며 실행 취소가 가능하다.
- 편집기 검사는 현재 맵만이 아니라 프로젝트의 모든 맵을 대상으로 한다. 새 프로젝트와 새 맵은 서로 다르다.
- 플레이 테스트는 선택한 맵 ID를 별도 전달한다. 맵 순서나 프로젝트 데이터는 변경하지 않으며 기존 메시지에서 ID를 생략하면 기존처럼 첫 맵으로 시작한다. 조각 독립 시험은 그 조각의 맵을 시작한다.
- 시험 전용 게임 창은 장면이 준비될 때까지 준비 화면을 표시해 기본 맵이 잠시 보이지 않게 한다.
- PASS: 실제 브라우저에서 예제 검사, 빈 맵 선택·플레이, 기존 맵 보존, 이전 예제 오류에 대한 명시적 복구, 재실행 및 준비 화면. 기존 파일·메시지 호환성 별도 시험.
