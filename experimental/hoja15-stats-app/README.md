# HOJA 1.5 통계 (교사 전용 · 휴대폰용 Apps Script)

게임 운영 프로젝트와 **분리된** 별도 Apps Script 웹 앱입니다. 게임 이용 기록 스프레드시트의 `EVENT_LOG`에서
**HOJA 1.5 승인 카트리지 기록(`usageSchemaVersion` = `A1`)만** 읽어 집계합니다. 쓰기·트리거·학생 정보 없음.

| 화면 | 내용 |
|---|---|
| 기간 | 오늘 / 7일 / 30일 / 전체 |
| 숫자 | 게임 시작 수, 하루 평균, 혼자 놀기 / 함께 놀기(팀전) |
| 그래프 | 날짜별(혼자·함께), 시간대(한국 시간), 요일 — 막대를 누르면 숫자 표시 |
| 목록 | 많이 고른 단원(게임 표시 이름), 팀 수, 학년, 교과, 한 번에 고른 단원 수 |

숫자는 5분 동안 캐시되고, **새로고침** 버튼은 바로 다시 계산합니다.

## 배포 (선생님이 한 번)
1. <https://script.google.com> → **새 프로젝트** → 이름 예: `HOJA 1.5 통계`.
2. 이 폴더의 파일을 그대로 붙여 넣기
   - `Code.gs` → 기본 `코드.gs` 내용 전체 교체
   - `Index.html` → **+ → HTML** 로 `Index` 만들고 붙여 넣기
   - `appsscript.json` → 프로젝트 설정에서 **"appsscript.json" 매니페스트 파일 표시** 켠 뒤 붙여 넣기
3. **배포 → 새 배포 → 웹 앱**: 실행 사용자 **나**, 액세스 권한 **나만** → 배포 → 권한 허용(스프레드시트 **읽기**만).
4. 휴대폰에서 웹 앱 주소를 열고(같은 Google 계정 로그인) 처음 한 번 **이용 기록 스프레드시트 주소**를 붙여 넣기.
   주소는 운영 게임 프로젝트의 스크립트 속성 `SMQ_USAGE_SPREADSHEET_ID`가 가리키는 파일(EVENT_LOG 시트가 있는 파일)입니다.
5. 휴대폰 브라우저 메뉴의 **홈 화면에 추가**로 앱처럼 쓸 수 있습니다.

### 폰에서 "현재 파일을 열 수 없습니다"가 뜰 때
- 크롬에 구글 계정이 여러 개 로그인돼 있으면 생기는 앱스크립트 공통 문제입니다. **크롬 시크릿 탭**(액세스가 '모든 사용자'일 때), 또는 통계 앱을 만든 계정 하나만 로그인한 브라우저로 여세요.
- 액세스를 '모든 사용자'로 두면 주소를 아는 사람은 **보기만** 가능합니다(게임 횟수만, 학생 정보 없음). **연결 시트 변경은 만든 계정으로 로그인했을 때만** 됩니다.

### 연결 시트 바꾸기
- 앱 맨 아래 **연결된 시트: (파일 이름)** 으로 지금 연결된 파일을 확인할 수 있습니다.
- **[연결 시트 바꾸기]** 를 누르고 새 스프레드시트 주소를 붙여 넣으면 바로 바뀝니다(캐시도 초기화).
- 앱을 새 버전으로 배포하기 전이라면: 통계 프로젝트 → **프로젝트 설정 → 스크립트 속성**에서 `HOJA15_STATS_SPREADSHEET_ID` 값을 원본 시트 ID로 바꾸고, `HOJA15_STATS_FIRST_ROW` 는 삭제하세요(5분 뒤 또는 새로고침 버튼으로 반영).

> 스프레드시트 ID는 이 통계 프로젝트의 스크립트 속성 `HOJA15_STATS_SPREADSHEET_ID`에만 저장되며 GitHub에는 없습니다.
> 코드를 고치면 **배포 관리 → 수정 → 새 버전**으로 같은 주소를 유지하세요.

## 시험
```
node --test experimental/hoja15-stats-app/hoja15_stats.test.mjs
```
합성 EVENT_LOG로 HOJA 1.5 기록만 세는지, 기간·혼자/함께·단원·시간대 합계, 캐시, 기록 없음, **쓰기 0회**를 확인합니다.
